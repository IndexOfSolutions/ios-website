### 6. Dynamics NAV to Business Central Upgrade
**URL:** /services/nav-to-business-central-upgrade

Migration service for businesses running any version of Microsoft Dynamics NAV (NAV 2009 through NAV 2018).

**Why Upgrade:**
- NAV versions progressively losing Microsoft support
- BC receives automatic feature updates twice a year
- Cloud deployment eliminates server maintenance costs
- Microsoft Copilot AI embedded in BC — not available in NAV
- Modern API integrations (e-commerce, banking, third-party apps)

**Upgrade Process:**
1. Audit current NAV version and customizations
2. Map which customizations to rebuild, replace, or retire in BC
3. Migrate data and configure BC environment
4. Parallel testing — run NAV and BC simultaneously before cutover
5. Go-live and decommission NAV

**FAQ:**
- Historical data: fully migrated (transactions and master data)
- Timeline: typically 2–4 months depending on NAV customizations
- Heavily customized NAV: yes, all customizations assessed and rebuilt as BC extensions

### 7. LS Central for Retail (Service/Blog Article)
**URL:** /services/ls-central-transforms-business-central-into-a-complete-retail-powerhouse

LS Central is a unified commerce platform built natively on top of Business Central, developed by LS Retail (a wholly-owned subsidiary of Aptos). It runs inside the same BC environment, sharing the same database, codebase, and UI.

**What LS Central Adds to BC:**
- **POS:** Fully featured, hardware/tablet/mobile, connected or offline, real-time sync to BC
- **Inventory & Replenishment:** Item-level tracking across stores/warehouses/in-transit, automated replenishment
- **Loyalty & Offers:** Points schemes, tiered memberships, promotions, voucher management
- **Hospitality & F&B:** Table management, kitchen display systems, recipe costing
- **Analytics & Forecasting:** Sales trends, basket analysis, store performance KPIs
- **Omnichannel Commerce:** Unified cart, click-and-collect, ship-from-store, returns across channels

**Architecture Advantage:** LS Central shares BC's data model — a POS sale posts a financial entry and updates inventory in real time. No replication lag, no reconciliation burden.

8. **Asset Management** — Laptops, phones, equipment with type, serial numbers, assignment history
